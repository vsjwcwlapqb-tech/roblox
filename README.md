# Frog Game

Rojo project for the Roblox Frog Game.

## Current build

- Fantasy pond and central Frog Island
- Sakura trees and falling petals
- Lotus flowers, lily pads, reeds, rocks and bushes
- Natural stone entrance path
- Six player display stalls with six placeholder doll slots each
- Decorative sailboat
- Frog spawn, race start and island entrance regions
- World attributes for the planned 6-player / 20-frog / 5-minute round structure

## Run in Roblox Studio

1. Clone this repository locally.
2. Install Rojo.
3. From the repository folder run `rojo serve`.
4. Open Roblox Studio and connect the Rojo plugin to the running server.
5. Start Play/Test. The server script generates the pond and island in Workspace.

The next development phase is the actual frog gameplay: spawning, movement, net catching, kiss interaction, frog-to-doll rolling, and the round/reset loop.
